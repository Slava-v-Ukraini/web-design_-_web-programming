# M-Corner — Преміальний веб-проєкт чоловічого догляду

Офіційний лендінг концептуального бренду чоловічого догляду **«M-Corner»** (Concept-Store & Online Platform). Проєкт розроблено відповідно до вимог 8 навчальних модулів веб-розробки з фокусом на семантику HTML5, чисту SCSS-архітектуру за методологією BEM, адаптивність та веб-доступність (a11y).

---

## 📌 Покриття 8 обов'язкових навчальних модулів

| № | Модуль | Реалізація в проєкті M-Corner |
|---|---|---|
| **1** | **Проєктування & Сітка** | 12-колонкова адаптивна сітка через SCSS-міксин `@mixin grid-12`, семантична типографіка (`Montserrat`, `Inter`), адаптивні розміри та масштабований лейаут для екранів від 320px до 1920px. |
| **2** | **Семантика HTML5 & Flexbox** | Повна семантична розмітка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`), структуровані заголовки `h1`–`h3`, чистий БЕМ (Block-Element-Modifier), Flexbox та Grid-вирівнювання. |
| **3** | **Адаптивність & Меню** | CSS-only бургер-меню через псевдоклас `:target` без сторонніх JS-бібліотек, ізоляція скролу через `overflow: hidden`, мобільна адаптація елементів керування. |
| **4** | **Мультимедіа** | Повноформатне безшовне фонове відео `<video>` в Hero-секції з атрибутами `autoplay`, `loop`, `muted`, `playsinline`, fallback-постером `hero-section.jpg`, `object-fit: cover` та градієнтним overlay-затемненням для читабельності тексту. |
| **5** | **HTML-форми & Таблиці** | Адаптивна порівняльна таблиця характеристик засобів (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`) з горизонтальним скролом на смартфонах; інтерактивна семантична форма запису на консультацію (`<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>`, `<textarea>`). |
| **6** | **UI-компоненти & Каталог** | 3 адаптивні картки каталогу однакової висоти через Flexbox/Grid, оновлені стани взаємодії `:hover`, `:focus` та `:focus-visible` для повної доступності з клавіатури. |
| **7** | **CSS-анімації & Ефекти** | Плавні переходи `transition`, мікроінтеракції `transform`, кастомна анімація циклічного відблиску бордерів кнопки Hero через `@keyframes btn-shimmer` (раз на 3 секунди), підтримка `@media (prefers-reduced-motion: reduce)`. |
| **8** | **Git & GitHub Pages** | Організація модульної файлової структури, збірка Parcel з відносними шляхами (`--public-url ./`), деплой на GitHub Pages. |

---

## 🛠 Стек технологій

- **HTML5** (Семантика, форми, медіа-теги, таблиці)
- **SCSS / SASS** (Змінні, міксини, 12-колонкова сітка, BEM-неймінг, модульність)
- **Parcel Bundler** (Автоматична компіляція SCSS, мініфікація, оптимізація медіа)
- **Git & GitHub Pages** (Контроль версій та хостинг)

## 🚀 Встановлення та запуск

1. **Клонувати репозиторій:**
   ```bash
   git clone <URL_РЕПОЗИТОРІЮ>
   cd landing_page
   ```

2. **Встановити залежності:**
   ```bash
   npm install
   ```

3. **Запустити локальний сервер розробки:**
   ```bash
   npm start
   ```
   Сторінка буде доступна за адресою: `http://localhost:1234`

4. **Зібрати оптимізований production-білд для GitHub Pages:**
   ```bash
   npm run build
   ```
   Готові файли згенеруються в директорію `dist/`.

---

## 🌐 Деплой на GitHub Pages

1. Створіть репозиторій на GitHub.
2. Запустіть білд:
   ```bash
   npm run build
   ```
3. Опублікуйте вміст директорії `dist/` у гілку `gh-pages` або налаштуйте GitHub Actions workflow.
4. У налаштуваннях репозиторію (**Settings -> Pages**) оберіть відповідне джерело публікації.
